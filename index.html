Gestrics

Gestrics is desktop software built for freelance translators and small translation practices. It helps manage outreach prospecting to new clients, project tracking, invoicing and payment collection — all installed and run entirely on the user's own computer, with no central server.

Emails are always sent through the user's own email account via SMTP and an app password.

Download for Windows
Windows 10/11 · Free install

Windows may show a "Windows protected your PC" warning during installation. This happens because the installer isn't digitally signed yet — it doesn't mean the app is unsafe. Click More info, then Run anyway to continue.

Gestrics

Gestrics es un software de escritorio para traductores autónomos y pequeños estudios de traducción. Ayuda a gestionar la prospección de nuevos clientes, el seguimiento de proyectos, la facturación y el cobro — todo instalado y ejecutado íntegramente en el ordenador del usuario, sin ningún servidor central.

Los correos siempre se envían a través de la propia cuenta de correo del usuario, mediante SMTP y una contraseña de aplicación.

Descargar para Windows
Windows 10/11 · Instalación gratuita

Es posible que Windows muestre un aviso de "Windows protegió tu PC" durante la instalación. Esto ocurre porque el instalador todavía no tiene firma digital — no significa que la app sea insegura. Haz clic en Más información y luego en Ejecutar de todas formas para continuar.
