Gestrics

Gestrics is desktop software built for freelance translators and small translation practices. It helps manage outreach prospecting to new clients, project tracking, invoicing and payment collection — all installed and run entirely on the user's own computer, with no central server.

Emails are always sent through the user's own email account via SMTP and an app password. Gestrics can optionally connect to the user's own Gmail or Outlook account, read-only, to automatically detect replies — never to send.
