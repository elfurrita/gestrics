Outreach Studio

Outreach Studio is desktop software built for freelance translators and small translation practices. It helps manage outreach prospecting to new clients, project tracking, invoicing and payment collection — all installed and run entirely on the user's own computer, with no central server.

Outreach Studio can optionally connect to the user's own Gmail or Outlook account to send prospecting emails, project deliveries, invoices and payment reminders directly from their own mailbox.
